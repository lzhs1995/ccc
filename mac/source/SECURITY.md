# Security

Agent tools can execute code with the user's privileges. This harness is an
orchestration guard, not a sandbox or a guarantee of correct model judgment.
Install only from a reviewed tag. Treat transcripts, receipts, configuration
backups, task packs and repository paths as private unless explicitly sanitized.

Do not submit credentials in public issues. Report vulnerabilities using GitHub
private vulnerability reporting when available; otherwise request a private
contact without posting exploit details or secrets. No automated production
authorization, remote transport, or credential management is supplied here.
