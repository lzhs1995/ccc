# Receiver identity and direct communication

Current policy follows [direct delivery](verified-compose-delivery.md). Send a
ready message during work, Goal or compaction without a composer/idle admission
gate. Bind the original live agent process, session and transcript before input;
never select a peer by title or the focused tab. Do not clear or repaste drafts.
Raw cmux communication is allowed; the bridge provides optional durable journals
and falls back when native input is unavailable before any input intent.

Only a new user message containing the unique marker in the original receiver
transcript proves reception. A key return, screen echo, queued attachment, hook,
assistant response or old user message does not. Full body reading, task ACK,
report acceptance and resource settlement remain separate.

After unconfirmed terminal input, one recorded extra Enter is allowed for visible
marker residue/compaction. Never paste twice. After uncertain native RPC input,
observe the original attempt only. Historical attempts retain their original
controller and budget; configuration installation does not prove active loading.
