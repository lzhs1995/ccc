# 0.4.36: original-supervisor recovery and upgrade compatibility

This release follows 0.4.35 with three bounded changes.

1. A complete Claude `⎿ Tip:` hint row above the composer no longer hides an
   active spinner. The draft remains byte-for-byte unchanged. Recognizing a
   hint does not authorize input during compaction, queued work or uncertainty.
2. Late ACK reconciliation can authenticate an embedded original Codex TUI
   using the complete original controller's readers. Kernel tool ancestry,
   native foreground, cmux UUID/workspace/TTY and stable repeated observations
   must agree. A missing managed-daemon proof alone is insufficient. The
   original supervisor runs apply; the maintenance owner cannot substitute.
3. CURRENT can interpret the fully reviewed immutable 0.4.35 file producer and
   issuer. That release retains its exact 13-member controller pins and only
   its existing reservation-inquiry capability. Older issuers cannot acquire
   future authority. In-flight controllers, episodes and pending inputs stay
   unchanged.

Use [late ACK reconciliation](late-handshake-ack.md) with the original receipt,
attempt, wire bytes and SHA pins. Preview is read-only. Apply still needs the
original supervisor and the original harness to have exited. ACK reconciliation
does not submit a formal task pack, settle a callback or prove notice body reading.

Focused tests cover Tip/spinner/draft boundaries, original-controller ACK
behavior, embedded owner/child/drift refusal and historical file capabilities.
The CI matrix runs the complete offline suite on Ubuntu/macOS and Python
3.10/3.14. A real read-only probe separately demonstrated correct maintenance
owner authentication and refusal to impersonate the B0024 business owner.

Installation, active-client automatic hooks, original-supervisor apply and a
complete native callback receipt require their own live evidence. This release
does not provide a missing native Codex control socket, reload an existing TUI,
change general embedded hook authentication or recover an exited Claude process.
Preserve the original session and pending evidence while resolving those cases.
