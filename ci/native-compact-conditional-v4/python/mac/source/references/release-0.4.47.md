# 0.4.47: explicit profiles, original controllers and evidence

This release keeps 0.4.46's immediate bidirectional communication policy:
normal work and native Goal continuation do not require a pause or idle turn.
Independent ready information may use the supported sender even while an
unrelated original message remains unconfirmed. Reconcile the original without
replay and preserve actual drafts.

`configuration_guardian.py reconcile-profile` repairs the owned hooks in one
explicit actual `--settings` file. Preview returns its exact original SHA.
Apply requires that SHA, complete CURRENT verification, the existing installation
lock and a private exact backup. It preserves non-hook values and foreign hooks,
checks the written hash and reports concurrent edits or failed readback without
overwriting a later writer. It does not start, unpause or rewrite the guardian job,
change provider selection, enable externally disabled hooks or certify loading.

Controller mismatch diagnostics include the recorded original and actual invoked
source, Python and pins. Tick/consume still refuse with zero input and no
consumption or state migration. A recorded controller is not newly authenticated
authority and the diagnostic never runs it.

The reviewed complete `0.4.46-37e945dea2e3` release is recognized for file
scheduling with its original 14 controller members, scheduler, descriptor and
13-controller issuer scope. Preserve any originally enrolled reservation-inquiry
capability; do not grant it through installation or an edited episode. Historical
issuers cannot enroll future or unreviewed controllers. No historical code is
imported or executed.

[Evidence and handoffs](collaboration-evidence-and-handoffs.md) consolidates
accepted field lessons about child execution, task notifications, honest
read-only claims, exact peer checks, fair inbox processing and runtime provenance.
It does not add research review rounds or transfer shared write ownership.

Offline regression and schema results belong to the tested source commit.
The inherited Claude verdict stays
`NO_BLOCKER_FOUND_IN_REVIEWED_SCOPE_PARTIAL`; it is not an overall review PASS
for this release. Publication, complete installation, actual automatic hooks,
