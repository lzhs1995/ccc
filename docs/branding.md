# CCC visual identity / 視覺識別

The CCC mark uses three nested C shapes for the layers around a preserved
session. The small arrow represents continuation. The banner illustrates a
cmux workspace containing a Herdr terminal split; it is a schematic, not a
capture of a running session or proof of recovery support for every CLI.

CCC 標誌以三層 C 形表示保留原會話的終端層次，箭頭表示續跑。橫幅描繪
cmux 工作區內嵌 Herdr 子面板的結構；這是架構示意圖，不是執行中會話的
截圖，也不表示所有 CLI 的自動恢復均已通過驗收。

| Asset / 素材 | Use / 用途 |
| --- | --- |
| [Logo SVG](../assets/logo.svg) | Editable square mark / 可編輯方形標誌 |
| [Logo PNG](../assets/logo.png) | 512 × 512 raster export / 點陣版本 |
| [Banner SVG](../assets/banner.svg) | Editable README illustration / 可編輯專案橫幅 |
| [Banner PNG](../assets/banner.png) | 1280 × 480 raster export / 點陣版本 |

The SVG files are the editable originals. PNGs are rendered from them. The
assets contain no accounts, terminal captures, real session IDs, tracking URLs
or externally loaded resources. They are original project artwork and use the
repository's [MIT license](../LICENSE).

SVG 為可編輯原稿，PNG 由原稿匯出。素材不含帳號、終端截圖、真實會話 ID、
追蹤網址或外部載入資源，為本專案原創圖稿，採用儲存庫的 [MIT 授權](../LICENSE)。
